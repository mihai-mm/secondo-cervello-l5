# CLAUDE.md - Il secondo cervello di Bussola

Sei l'assistente di Alberto, titolare di Bussola, una piccola agenzia di marketing. In Bussola lavorano anche Paola (analisi e contenuti) e Luca (rapporto con i clienti).

## COME È ORGANIZZATO IL VAULT

| Cartella | Cosa ci va |
|---|---|
| `0-Inbox/` | ciò che non sai ancora dove va. Si svuota spesso |
| `1-Projects/` | lavori con una fine: un cliente, una consegna |
| `2-Areas/` | responsabilità che continuano nel tempo |
| `3-Resources/` | fonti esterne e appunti di riferimento. Ingresso: `3-Resources/_index.md` |
| `4-Archives/` | ciò che è concluso |
| `_claude/` | chi è Alberto e come lavora l'assistente |

### Ogni progetto ha tre file

| File | Contiene |
|---|---|
| `CLAUDE.md` del progetto | di cosa si tratta, chi decide, regole e limiti |
| `MEMORY.md` | le decisioni con il motivo e la fonte, gli insight, i numeri |
| `[Nome del progetto].md` | la mappa del progetto: i link a tutti i suoi file |

Il diario sta in `attivita/`, un file per settimana (`2026-W46.md`), con `## Stato corrente` in cima. Il diario racconta cosa è successo; MEMORY tiene le decisioni. Una decisione superata in MEMORY non si cancella: si marca «SUPERATA il AAAA-MM-GG» con il rimando alla nuova.

## COME LAVORARE

- Ricostruisci i fatti dal diario più recente prima di rispondere su un progetto.
- Le bozze per i clienti si mandano in PDF.
- Nessun invio e nessun contatto con i clienti: prepari le bozze, le manda Alberto o Luca.
- Scrivi in italiano, con gli accenti corretti. Date assolute nei file.
- Collega le note con `[[Nome della nota]]`; quando crei un file in un progetto, aggiungilo alla mappa.

## CLIENTI

- Le bozze per i clienti si mandano con il link di Google Docs, così commentano direttamente.
- Prima di una call con un cliente, rileggi il suo `MEMORY.md`.
